Email Data Pipeline

Run in order: 1 → 2 → 3 → 4

Step 1 — Lead Enrichment

EMAIL_PERFORMANCE_MAREKTO_LEADS_DATA
Maps every Marketo lead to their SFDC contact record. One row per lead with SFDC attributes attached.
PV_LEAD (Marketo) PV_LEAD_CONTACT (SFDC)

Step 2 — Email Activity Fact Table

FINAL_EMAIL_ACTIVITY_TABLE
One row per email send event. Enriched with delivery, bounce, open, click, unsubscribe status + lead data from Step 1.
PV_ACTIVITY_SEND_EMAIL 6 Activity CTEs Step 1 table

Step 3 — Campaign Mapping

Email_campaign_mapping
Fuzzy-matches each email name (PRIMARY_ATTRIBUTE_VALUE) to a PV_CAMPAIGN record. Scores using Jaccard, Jaro-Winkler, edit distance.
Step 2 table (email names) PV_CAMPAIGN

Step 4 — Dashboard Table (Tableau)

EMAIL_PERFORMANCE_DASHBOARD_FINAL
Combines email activity + campaign mapping + account enrichment + fiscal time. This is the final table consumed by Tableau.
Step 2 table (driver) Step 3 table PV_ACCOUNT PV_TIME EMAIL_OPT_IN_FLAG_Y
Key: PV_LEAD_CONTACT is used only once (Step 1). All subsequent steps get lead/contact/account data through the pipeline, avoiding redundant joins.

Venn Diagrams — Left Joins

Shows what data comes from where in each step

Step 1: PV_LEAD left join PV_LEAD_CONTACT

LEFT JOIN keeps all Marketo leads. ~110K leads have no SFDC match (SFDC_MAPPING = NO). These still flow through the pipeline with NULL SFDC attributes.

Step 2: Send Events left join Activity CTEs + Lead Data

All 6 activity joins are pre-aggregated CTEs (MIN/MAX) to prevent fanout. Each send event gets at most 1 matching row from each activity type.

Step 4: Email Activity (driver) + Campaign Map + Account + Time

FINAL_EMAIL_ACTIVITY_TABLE is the driver. All rows preserved. Campaign mapping may create fanout (use COUNT DISTINCT E_ID for metrics). PV_ACCOUNT and PV_TIME enrich without duplication.

Join Details

Every join in the pipeline explained

Step 1: Lead Enrichment

PV_LEAD → PV_LEAD_CONTACT

Type: LEFT JOIN
Key: COALESCE(SFDC_CONTACT_ID, SFDC_LEAD_ID) = LEAD_CONTACT_ID
Purpose: Attach SFDC contact info (email, title, company, account, geo) to Marketo leads
Unmatched: ~110K leads with no SFDC record → SFDC_MAPPING = NO

Step 2: Email Activity

SEND_EMAIL → FIRST_DELIVERED

Type: LEFT JOIN (pre-aggregated CTE)
LEAD_ID + PRIMARY_ATTRIBUTE_VALUE_ID + CAMPAIGN_RUN_ID
MIN(ACTIVITY_DATE) → first delivery date

SEND_EMAIL → FIRST_BOUNCED

Type: LEFT JOIN (pre-aggregated CTE)
LEAD_ID + PRIMARY_ATTRIBUTE_VALUE_ID + CAMPAIGN_RUN_ID
MIN(ACTIVITY_DATE) → first hard bounce

SEND_EMAIL → LAST_BOUNCED_SOFT

Type: LEFT JOIN (pre-aggregated CTE)
LEAD_ID + PRIMARY_ATTRIBUTE_VALUE_ID + CAMPAIGN_RUN_ID
MAX(ACTIVITY_DATE) → last soft bounce

SEND_EMAIL → FIRST_OPENS / FIRST_CLICKS / FIRST_UNSUBSCRIBE

Type: LEFT JOIN (pre-aggregated CTEs)
LEAD_ID + PRIMARY_ATTRIBUTE_VALUE_ID + CAMPAIGN_RUN_ID
MIN(ACTIVITY_DATE) for each

SEND_EMAIL → Step 1 table

Type: LEFT JOIN
s.LEAD_ID = ld.MARKETO_LEAD_ID
Attaches lead/contact enrichment data to each send event

Step 3: Campaign Mapping

Email Names → PV_CAMPAIGN (fuzzy)

Type: LEFT JOIN with blocking + scoring
FY quarter / Region / prefix match
Scored with Jaccard (35%) + Jaro-Winkler (20%) + Edit Distance (20%) + bonuses (25%)
Best match per email name (ROW_NUMBER = 1)

Step 4: Dashboard Final

Email Activity → Campaign Mapping

Type: LEFT JOIN
CAST(a.CAMPAIGN_ID AS VARCHAR) = CAST(b.att_CAMPAIGN_ID AS VARCHAR)
May cause fanout if 1 campaign matches multiple mappings. Use COUNT(DISTINCT E_ID).

Email Activity → PV_ACCOUNT

Type: LEFT JOIN
a.ACCOUNT_ID = ac.ACCOUNT_ID
Adds industry + DRVD_SEGMENT for THEATRE logic

Email Activity → PV_TIME

Type: LEFT JOIN
a.SEND_DATE = c.DAY_END_DATE
Adds fiscal quarter, week, month, year

Email Activity → EMAIL_OPT_IN_FLAG_Y

Type: LEFT JOIN
a.LEAD_CONTACT_ID = opt.LEAD_CONTACT_ID
Adds email opt-in flag
